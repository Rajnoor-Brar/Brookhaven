# Literature

The photoproduction papers this study leans on. The PDFs are kept out of git (`.gitignore`);
this list says what to put here.

- 646026_1_En_361_Chapter_Author.pdf, FEDD_42.pdf, Inclusivejetphotoproduction_AbhasRathi.pdf,
  PGP1_2024_V23107_AbhasRathi.pdf, PH518P_V23107_AbhasRathi.pdf: Rathi & Palni, inclusive-jet
  photoproduction with Pythia for the EIC
- Prabi_inclusive-jet_dijet_GU.pdf: ZEUS data against Pythia 8
- [IMP]inclu_dijets.pdf: ZEUS 2012, inclusive jets and dijets in photoproduction (arXiv:1205.6153)
- [imp]inclu_rosetta.pdf: H1, jets in photoproduction
- [imp]intro_incl.pdf: ZEUS, jets in γp
- [imp]inclsuve_eic.pdf: Klasen et al., nuclear PDFs from jets at an EIC
- nr_photoproduction_pythia.pdf, r_modelling_photo_processes.pdf, r_photoproduction_evengens.pdf,
  2406.10403v1.pdf: photoproduction in Pythia (VMD, the photon's structure)
